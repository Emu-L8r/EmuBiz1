## ⚠️ Identified Problems

### 1. Massive Test Suite Regression
The test suite is effectively "dead code" until major refactoring is performed. 
*   **Unresolved References:** Common Mockito/Mockk and Coroutine test helpers are missing imports in almost every test file.
*   **Stale Mocks:** Constructor changes in `InvoiceRepository` (adding `InvoiceApi`) have not been propagated to `InvoiceRepositoryTest`.
*   **Unsafe Nullability:** Test files like `InvoiceOperationsTest.kt` contain prohibited operator calls on nullable types.

### 2. UI Performance (Main Thread Bloat)
Initialization logic in `BizapApplication` and `LandingViewModel` is triggering large frame skips.
*   **Cause:** Data seeding and snapshot backfilling are likely running too close to the UI thread's start sequence.

### 3. Missing API Security
*   **Exchange Rates:** The app logs "ExchangeRateWorker: No API key configured. Skipping rate sync." while the build system defaults to an empty string.
