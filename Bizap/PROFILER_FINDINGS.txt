PROFILER SETUP INSTRUCTIONS
================================================================================

1. Android Studio Profiler Setup:
   - Launch Android Studio
   - Open Profiler tab (View > Tool Windows > Profiler)
   - Connect device/emulator via ADB
   - Select "Bizap" app process
   - Available profilers: CPU, Memory, Network, Energy

2. Recording CPU Profile (1-2 minutes):
   - Click "CPU" in Profiler
   - Start recording (use "Callstack Sample Recording" mode)
   - Perform typical user actions:
     * Navigate to Dashboard
     * Create a new invoice
     * Add line items
     * Generate PDF
     * Switch between GUI1 and GUI2
   - Stop recording after 1-2 minutes
   - Analyze call stack and flame graph

3. Recording Memory Profile (1-2 minutes):
   - Click "Memory" in Profiler
   - Start recording
   - Perform same user actions as CPU profiling
   - Force GC via Profiler
   - Capture heap dump
   - Analyze object allocations and leaks

================================================================================
APPENDIX: PROFILING COMMANDS & TOOLS
================================================================================

ADB Commands for Profiling:
```bash
# List running processes
adb shell ps | grep bizap

# Monitor CPU usage
adb shell top | grep bizap

# Capture memory snapshot
adb shell dumpsys meminfo com.emul8r.bizap

# Force garbage collection
adb shell am broadcast -a com.android.studio.profiler.action.FORCE_GC \
  -p com.emul8r.bizap

# Capture heap dump
adb shell am dumpheap com.emul8r.bizap /data/local/tmp/heap.hprof
adb pull /data/local/tmp/heap.hprof
```

Alternative Tools:
- Android Studio Profiler (primary tool)
- LeakCanary (memory leak detection)
- Systrace (system-wide performance)
- Perfetto (advanced profiling)
