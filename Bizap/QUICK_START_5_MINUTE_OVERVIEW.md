## 💡 KEY FEATURES

### How Color Injection Works
```
User Settings
    ↓
Brand Colors (Primary, Secondary, Accent)
    ↓
PDF Generation
    ↓
Automatic Color Injection
    ↓
Professional Branded PDF ✨
```

### Spacing System
```
Regular text with proper spacing:
4px (xs) | 8px (sm) | 12px (md) | 16px (lg) | 24px (xl)
```

### Typography Classes
```
<h1 class="heading-primary">   → Bold, 22pt
<h2 class="heading-secondary">  → Semibold, 18pt
<h3 class="heading-tertiary">   → Semibold, 14pt
<p class="body-text">            → Regular, 11pt
<span class="caption-text">      → Small, 9pt
```
