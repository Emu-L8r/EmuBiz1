BATTERY HISTORIAN SETUP INSTRUCTIONS
================================================================================

1. Setup Options:

   OPTION A: Use Web Version (Recommended for quick analysis)
   - Visit: https://www.batteryhistorian.com/
   - No installation required
   - Upload bugreport.txt for instant analysis
   
   OPTION B: Install Locally (Advanced users)
   - Requires: Docker
   - Command: docker run -p 9999:9999 gcr.io/android-battery-historian/stable:3.1
   - Access: http://localhost:9999
   - Benefits: Offline analysis, privacy

2. Generate Battery Dump (Android device/emulator):

   Step 1: Reset battery stats
   ```bash
   adb shell dumpsys batterystats --reset
   ```
   
   Step 2: Use the app normally for 30-60 minutes
   - Open Bizap
   - Navigate between screens
   - Create invoices
   - Generate PDFs
   - Let app idle in background
   
   Step 3: Capture battery report
   ```bash
   adb bugreport bugreport.zip
   unzip bugreport.zip
   ```
   
   Step 4: Upload bugreport.txt to Battery Historian
   - Open Battery Historian (web or local)
   - Upload the bugreport-*.txt file
   - Analyze results

3. Alternative: Quick Battery Stats Check
   ```bash
   adb shell dumpsys batterystats com.emul8r.bizap
   ```

APPENDIX: BATTERY TESTING COMMANDS
================================================================================

Quick Battery Stats:
```bash
# Current battery level
adb shell dumpsys battery | grep level

# Battery status
adb shell dumpsys battery

# App-specific battery usage
adb shell dumpsys batterystats com.emul8r.bizap

# Reset battery stats (before testing)
adb shell dumpsys batterystats --reset

# Full bugreport (for Battery Historian)
adb bugreport bugreport.zip
```

Battery Testing Best Practices:
1. Fully charge device before testing
2. Reset battery stats before test session
3. Use device normally for 30-60 minutes
4. Capture bugreport after session
5. Repeat test 3 times for accuracy
6. Test on different Android versions
7. Compare with competitor apps
