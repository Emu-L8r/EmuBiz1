## 🔑 KEY CONCEPTS

### CSS Variable System
- **Purpose:** Enable per-invoice brand customization
- **Usage:** All colors defined as CSS variables
- **Benefits:** Easy to update, consistent styling
- **Documentation:** See INVOICE_IMPROVEMENTS_QUICK_REFERENCE.md

### Semantic Typography Classes
- **Purpose:** Consistent text hierarchy
- **Classes:** heading-primary, heading-secondary, body-text, caption-text, etc.
- **Benefits:** Clear visual distinction, maintainable CSS
- **Documentation:** See INVOICE_IMPROVEMENTS_QUICK_REFERENCE.md

### Color Injection
- **Purpose:** Apply brand colors from InvoiceSettings to PDFs
- **Process:** Validate → Map → Inject → Generate
- **Benefits:** Dynamic customization without code changes
- **Documentation:** See INVOICE_IMPROVEMENTS_QUICK_REFERENCE.md

### 8px Spacing System
- **Purpose:** Professional, consistent layout
- **Units:** 4px (xs), 8px (sm), 12px (md), 16px (lg), 24px (xl)
- **Benefits:** Balanced, rhythmic design
- **Documentation:** See INVOICE_IMPROVEMENTS_QUICK_REFERENCE.md
